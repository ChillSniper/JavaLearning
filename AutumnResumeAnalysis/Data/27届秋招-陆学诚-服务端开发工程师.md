### 知乎舆情分析Agent

:::

::: right

构建时间：2026/05-2026/07

:::

- Github Link: <https://github.com/ChillSniper/ZhiHu-Analysis-Agent>
- **项目简介：**

本项目为面向**舆情**分析人员的**分析工作台**。导入合规的知乎式讨论 CSV 后，可用自然语言发起趋势、关键词和风险分析，系统生成带原帖及指标证据的报告，并交由人工审核。

- **重点内容：**
  - **设计并落地多角色 Workflow Agent 执行链路**：将自然语言任务拆成风险、趋势、关键词等任务并行执行，再完成证据校验、报告生成和人工审核；通过 7 个结构化 Tool 隔离模型与数据库；
  - **建设证据驱动报告生成与事实校验机制**：实现报告事实校验，逐项检查报告数值与 Tool 结果；60 条离线流程评测中，意图、Tool、证据与注入隔离检查均为 100%、P50 84.36ms、P95 129.49ms；
  - **设计并实现可恢复的多角色 Agent DAG 执行引擎**：实现可恢复的工作流引擎，通过数据库租约协调并发、检查点保存进度，支持中断续跑和 SSE 轨迹续传；通过幂等键复用 Tool 结果并防止重复报告。
