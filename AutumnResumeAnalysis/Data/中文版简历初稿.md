### 知乎舆情分析Agent

:::

::: right

构建时间：2026/06-至今

:::

- Github Link: <https://github.com/ChillSniper/ZhiHu-Analysis-Agent>
- **项目简介：**

本项目为 FastAPI、Vue3 和 OpenAI-compatible Provider 构建的**舆情分析工作台**。系统支持导入合法获取的知乎式公开讨论 CSV，通过自然语言发起**研判任务**，由 Planner 生成结构化 DAG，调用**受控分析工具**，通过 Evidence Verifier、Claim Verifier **校验事实与证据**，最终进入人工审核生成可回放报告。

- **产出内容：**
  - **设计并落地多角色 Workflow Agent 执行链路**：实现 Planner -> 并行 Worker -> Evidence Verifier -> Report Synthesizer -> Claim Verifier -> Human Review 的有界流程；Agent 只能通过 7 个注册 Tool 获取业务数据，Tool 均具备严格的 ArgsModel / ResultModel 和输入输出 JSON Schema，隔离模型与 ORM/SQL 的直接访问，从而降低提示注入和无依据生成风险。
  - **建设证据驱动报告生成与事实校验机制**：每个事实 Claim 必须携带 value / unit / operator 等信息，Verifier 从实际 Tool Result 中按路径回查并比对数值；在 60 条任务离线评测中，意图识别、Tool 选择、证据引用和注入隔离均达到 100%，离线执行 P50 84.36ms、P95 129.49ms，平均 6.45 steps。
  - **设计并实现可恢复的多角色 Agent DAG 执行引擎**：使用版本化 Pydantic WorkflowState 与 checkpoint 持久化节点进度，通过 SQLAlchemy 条件 UPDATE、Run/Task lease token 及心跳机制实现并发抢占和超时接管；基于单调事件流与 SSE Last-Event-ID 支持执行轨迹续传，并以 ToolCall 幂等键和 agent_run_id 唯一约束避免重复的业务结果。
