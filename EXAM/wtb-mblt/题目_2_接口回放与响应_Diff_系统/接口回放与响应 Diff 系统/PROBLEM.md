# 接口回放与响应 Diff 系统

## 背景

服务在迭代过程中，接口响应经常发生静默变化——字段被删了、类型改了、结构调整了——但没有任何拦截。

你需要实现一个 Diff 工具的核心能力：给定同一批接口的「旧版响应」和「新版响应」，自动识别差异并生成报告，帮助质量同学快速定位变更点。

`resources/` 目录已提供两份数据文件：
- `old_responses.json`：旧版接口响应快照（基准）
- `new_responses.json`：新版接口响应快照（待比对）

## 输入数据格式

两份文件结构相同，均为数组，每条记录对应一次接口响应：

```json
[
  {
    "id": "req_001",
    "description": "获取文章详情",
    "request": { "method": "GET", "path": "/api/articles/1" },
    "response": {
      "status": 200,
      "body": { ... }
    }
  }
]
```

以 `id` 字段对齐新旧两份数据中的对应记录。

## 总体约束

- 编程语言不限
- diff 核心逻辑自己实现，可以用语言内置数据结构，也可以借助通用比较库（如 deep-diff、jsondiffpatch），但要能解释清楚
- 动态字段的忽略规则必须**可配置**（通过配置文件管理），不能硬编码在 diff 逻辑里

## 动态字段说明

以下字段在每次请求时都会变化，diff 时必须忽略，否则会产生大量误报：

```
timestamp, traceId, request_id, created_at
```

忽略规则通过配置文件管理，格式自定义（JSON/YAML 均可），例如：

```json
{
  "ignore_fields": ["timestamp", "traceId", "request_id", "created_at"]
}
```

## 必做功能

### 1. 字段级 Diff

逐条比对新旧响应，识别以下差异类型：

| Diff 类型 | 说明 |
|-----------|------|
| 状态码变更 | HTTP status code 不一致 |
| 字段删除 | 旧版有，新版没有 |
| 字段新增 | 旧版没有，新版有 |
| 字段类型变更 | 同一字段类型不同（如 string → number） |
| 字段值变更 | 同一字段类型相同但值不同（动态字段除外） |

diff 颗粒度需要到**字段路径级别**（如 `data.author_email`），不能只做整体字符串比较。

### 2. 动态字段忽略

读取配置文件，diff 时跳过配置中列出的字段，不将其计入差异。

### 3. Diff 报告

输出 `DIFF_REPORT.md`，至少包含：

- 汇总：总记录数、有差异数、无差异数
- 每条有差异记录的明细：请求描述、字段路径、diff 类型、旧值、新值

示例格式：

```markdown
## 汇总

| 总记录数 | 有差异 | 无差异 |
|----------|--------|--------|
| 7 | 4 | 3 |

## 差异明细

### req_001 - 获取文章详情（GET /api/articles/1）

| 字段路径 | Diff 类型 | 旧版 | 新版 |
|----------|-----------|------|------|
| data.like_count | 类型变更 | string "128" | number 128 |
| data.author_email | 字段删除 | "creator@kuaishou.com" | 不存在 |
| data.updated_at | 字段新增 | 不存在 | "2024-06-01T00:00:00Z" |
```

## 进阶（加分项）

忽略太多和忽略太少一样糟糕。比如 `like_count` 从 `"128"` 变成 `128` 是类型变更，是真实变更，应该被报出来——而不是因为"值都是数字"就被吞掉。

除此之外：
- 动态字段支持通配符匹配（如 `*_at` 匹配所有以 `_at` 结尾的字段）
- 数组类型字段，支持「忽略顺序」比对模式
- 报告中对「疑似动态字段」（未配置但新旧值每条都不同）给出提示

## 验收要求

1. 能读取两份 JSON 文件并逐条比对
2. Diff 报告正确识别出数据中存在的所有差异类型
3. 动态字段不出现在报告中（无误报）
4. 报告格式清晰，字段路径可读

## 交付物

- 完整源码
- 一键运行脚本
- `DIFF_REPORT.md`（运行后生成）
- 简要说明：diff 算法设计思路、配置文件格式
