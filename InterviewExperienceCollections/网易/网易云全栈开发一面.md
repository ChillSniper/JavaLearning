# 网易云音乐全栈开发工程师面试

一、面试官核心提问
1. 项目与基础背景
请做自我介绍并介绍最具代表性的项目经历。
研究生阶段参与的容器镜像安全防护、嵌入式故障分析项目是否为学校承接的导师项目？
你的Java技术掌握程度如何，有没有相关全栈项目实践？
2. Java技术考察
ArrayList与LinkedList的底层实现、适用场景及线程安全性有何区别？多线程环境下如何保证集合操作的线程安全？
你对JVM核心特性、垃圾回收排查方法及主流垃圾回收器有哪些了解？
线程池的核心作用是什么？线程池与队列满员后的拒绝策略、CPU密集型任务的线程数设置、线程池监控指标分别是什么？
3. 数据库技术考察
单从数据库层面，如何排查并优化SQL慢查询？
MySQL索引失效的常见场景有哪些？什么是联合索引的最左前缀原则？
面对每日千万级的播放记录，如何设计存储方案支撑高并发写入需求？
4. 后端通用技术考察
服务器端限流的主流思路有哪些？滑动窗口、令牌桶有哪些快捷实现框架？流量高峰下的服务降级是什么概念，有哪些处理措施？
从点击播放到歌曲实际播放，底层网络调用的完整流程是怎样的？域名解析的具体逻辑是什么？
面向全国用户，可通过哪些技术手段优化歌曲播放与下载速度？
线程与协程的核心区别是什么？线上CPU飙升该如何逐步排查？
Prometheus的指标采集逻辑是什么，与Grafana如何交互？
日志实时采集如何与ELK集成？高并发场景下怎么设计日志防丢失策略？
你对NoSQL非关系型存储有多少了解？用Java如何实现位图权限管理？
5. AI技术考察
近半年你在AI相关技术上有哪些学习积累？LangChain与LangGraph的核心区别是什么？
你日常使用哪些AI生码工具，如何保证生成代码的准确率？
二、候选人反问及面试官答复
问题：公司办公地点位于杭州哪个区域？
答复：地处杭州滨江区高新区，周边聚集等多家科技企业，是互联网产业集中片区。
问题：公司内部AI工具有没有月度额度限制，是否有强制使用量要求？
答复：相关细节不便对外透露，内部提供多款大模型可供选择，使用额度设置充足，可满足日常工作需求。
问题：面试结果多久反馈？整体招聘流程有几轮？
答复：结果将在5、7个工作日内由HR通知；整体面试共4、5轮，包含HR环节。本次全栈岗位更偏向后端，要求开发者同时完成前后端需求交付，不再严格拆分前后端职责。
