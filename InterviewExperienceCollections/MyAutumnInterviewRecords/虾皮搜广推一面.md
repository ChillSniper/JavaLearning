### 优先级二 讲清 DAG 调度与运行环境

**对应证据：** 53:20 的回答集中在队列、信号量和线程池调整，依赖满足条件与异常结束没有说明清楚。

**需要掌握的内容：** 就绪队列、未满足依赖数量、并发任务计数、成功完成通知、环路检查、异常传播和执行结束条件。若使用 Node.js，还需要分清异步 I/O 并发、Event Loop 和 CPU 工作的执行方式。

**练习案例：** 设任务 `C` 依赖 `A` 和 `B`，任务 `D` 仅依赖 `B`，并发上限为 2。`A` 和 `B` 可以同时启动。若 `B` 提前完成，`D` 在满足自身条件后应当能够使用空余名额；`C` 继续等待 `A`。用真实任务执行记录检查这一行为，观察启动、完成顺序及最大并发数量。

**验收标准：** 能够独立解释为什么队列、信号量各自不足以保证全部正确性，并对以下情况给出可运行验证：

| 情况 | 应当验证的行为 |
| --- | --- |
| 单节点和链式依赖 | 节点执行次数正确，后继等待前驱完成 |
| 多个独立节点 | 在允许范围内并发，最大执行数量不超过上限 |
| 多前驱汇合 | 所有必要前驱成功后，后继仅执行一次 |
| 无关慢任务 | 不阻止已经满足依赖的其他任务使用空余名额 |
| 环路和缺失依赖 | 执行前报告明确的输入错误 |
| 并发上限为 1 | 任务按依赖要求串行执行 |
| 非法并发上限 | 立即报告输入错误 |
| 任务异常 | 按明确语义终止并传播异常，相关后继不误执行 |

这张表属于练习要求。本次材料没有提供现场实现，上述测试尚未针对现场代码执行。
