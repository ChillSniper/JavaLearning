**参考回答：** 令 prefix 表示从数组开头到当前元素的累计和。某个连续区间满足目标，等价于此前某个前缀和等于 prefix-target。我用哈希表记录已经出现的前缀和及其次数，先累计 freq[prefix-target] 到答案，再把当前 prefix 的次数增加。初始化 freq[0]=1，用来统计从第一个元素开始的区间；顺序上先查询再记录，避免 target=0 时把空区间计入。时间复杂度平均为 O(N)，额外空间为 O(N)，累计和与答案使用 long long，并要求数值范围能够容纳累计和及相关运算。

```cpp
#include <unordered_map>
#include <vector>

long long countSubarrays(const std::vector<long long>& values,
                         long long target) {
    std::unordered_map<long long, long long> freq;
    freq[0] = 1;
    long long prefix = 0;
    long long answer = 0;
    for (long long value : values) {
        prefix += value;
        auto it = freq.find(prefix - target);
        if (it != freq.end()) {
            answer += it->second;
        }
        ++freq[prefix];
    }
    return answer;
}
```

例如 values=[1,-1,1]、target=1，三个有效区间分别为第一个元素、第三个元素和整个数组，答案为 3。freq 保存每个前缀和值出现的数量，由此统计所有可用的左侧边界，不需要逐个保存边界位置。
