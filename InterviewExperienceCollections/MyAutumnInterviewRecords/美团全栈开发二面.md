### 46. 完成最长子串算法题，并说明时间复杂度。

**现场表现：** 42:33 出题，47:26 左右表示完成，面试官随后继续测试；47:49 提到 `O(n)`。完整题面、测试输入和现场代码缺失，本题不计入数值评分。

**参考题型，按对话推断：** 如果题目要求“最长无重复字符子串的长度”，可以使用滑动窗口。如果原题还要求其他条件，需要使用对应解法，以下代码只服务这一明确题型。

**参考回答：** 我维护一个没有重复字符的连续窗口，用 `lastSeen` 记录每个字符最近出现的位置。右侧加入字符时，如果它之前出现过，就把 `left` 更新为当前位置与上次位置后一位的较大值，保证左边界只向前移动。每次使用窗口长度更新答案。每个字符处理一次，HashMap 操作按平均常数时间计算，时间复杂度为 `O(n)`。

```java
import java.util.HashMap;
import java.util.Map;
import java.util.Objects;

public class LongestSubstring {
    public static int lengthOfLongestSubstring(String s) {
        Objects.requireNonNull(s);
        int[] codePoints = s.codePoints().toArray();
        Map<Integer, Integer> lastSeen = new HashMap<>();
        int left = 0;
        int best = 0;

        for (int right = 0; right < codePoints.length; right++) {
            Integer previous = lastSeen.put(codePoints[right], right);
            if (previous != null) {
                left = Math.max(left, previous + 1);
            }
            best = Math.max(best, right - left + 1);
        }
        return best;
    }
}
```

这里把“字符”定义为 Unicode code point，长度按 code point 计算；组合字符和完整可视字符的划分需要另外定义。`codePoints` 数组占用 `O(n)` 空间，因此整体额外空间为 `O(n)`。`null` 输入直接抛出异常，空字符串返回零。

检查用例包括空字符串、`abcabcbb → 3`、`bbbbb → 1`、`pwwkew → 3`、`abba → 2`、`dvdf → 3`、`😀a😀b → 3`。其中 `abba` 可以检查 `left` 是否错误地向前回移。参考实现已与独立的枚举子串方法比较，共验证 97,390 个输入，并检查了 `null` 输入处理。该结果只证明参考实现的验证情况。
